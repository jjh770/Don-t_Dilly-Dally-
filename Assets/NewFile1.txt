Pushable Item 시스템은 플레이어가 특정 오브젝트를 잡고 밀거나 당길 수 있는 상호작용 시스템이다.

플레이어는 오브젝트와 가까이 있을 때 상호작용을 시작할 수 있으며, 상호작용 상태에서는 플레이어의 이동에 따라 오브젝트가 함께 이동한다.

이 시스템은 다음과 같은 게임플레이를 지원한다.

수술 장비 이동

큰 트레이 이동

기계 위치 조정

협동 플레이 기반 오브젝트 이동

2. Pushable Item 구조

PushableItem은 IPushable 인터페이스를 구현하는 상호작용 가능한 오브젝트이다.

필수 컴포넌트

Rigidbody

Collider

Rigidbody는 물리 기반 이동을 위해 필요하며, Collider는 플레이어와의 상호작용 판정을 위해 사용된다.

3. 상태 정의

PushableItem은 다음 상태를 가진다.

Idle 상태

플레이어와 상호작용하지 않는 상태

자유롭게 위치해 있는 상태

IsInteracting = false
Interacting 상태

플레이어가 아이템을 잡은 상태

플레이어 이동에 따라 아이템이 같이 이동한다

IsInteracting = true
4. 상호작용 흐름
1. 상호작용 시작

플레이어가 PushableItem 근처에서 상호작용 키를 누르면 Interact()가 호출된다.

동작

IsInteracting 상태 true

플레이어 애니메이션 변경

플레이어 이동 속도 감소

아이템이 플레이어와 고정된 상태가 된다

예시

플레이어 ── 아이템
   ↑
잡은 상태
2. 이동 중 (Push / Pull)

플레이어가 이동하면 Push()가 호출된다.

Push 시스템의 핵심 규칙

아이템은 플레이어 이동 방향으로 이동한다

아이템 속도 = 플레이어 속도

플레이어 이동 속도는 감소한다

Rigidbody를 통해 이동 처리한다

예시

플레이어 → 이동
아이템 → 같이 이동
3. 상호작용 종료

플레이어가 상호작용 키를 다시 누르거나 일정 거리 이상 떨어지면 StopInteract()가 호출된다.

동작

IsInteracting = false

플레이어 애니메이션 복귀

아이템 이동 중지

5. 이동 규칙

PushableItem 이동 규칙

아이템은 플레이어 이동 방향으로 이동한다

플레이어 속도와 동일한 속도로 이동한다

플레이어 이동 속도는 일반 이동보다 느려진다

Rigidbody.MovePosition 또는 Velocity를 이용해 이동한다

물리 충돌은 유지된다

6. 플레이어 제약

아이템을 밀거나 당기는 동안 다음 제약이 적용된다.

플레이어 이동 속도 감소

다른 아이템을 들 수 없음

던지기 불가능

상호작용 제한

7. 애니메이션

Pushable Item 상호작용 중 플레이어 애니메이션 상태

상호작용 시작

IsGrabbing = true

이동 중

IsPushing = true
또는
IsPulling = true

상호작용 종료

IsGrabbing = false
IsPushing = false
IsPulling = false
